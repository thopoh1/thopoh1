# thopoh1

Zweiter Account von **Thomas Pohlmann** — hier entsteht die öffentliche Seite des
FidoNet-Projekts **FidoWeb BBS**.

## Worum es geht

Eine FidoNet-BBS, die komplett in reinem PHP läuft: BinkP-Mailer (Client **und**
Server), EchoMail-/NetMail-Tosser, Type-2/2+-Paketbau, Router, Nodelist- und
Pointlisten-Verwaltung, AreaFix sowie eine vollständige Web-Oberfläche mit Foren,
NetMail, Profilen und Admin-Panel. Kein `binkd`, kein `ifmail`, kein externer
Tosser — alles nachvollziehbar in PHP.
